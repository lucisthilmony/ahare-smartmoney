# 实验C：行业指数择强底仓（strong3 的同构外推）· 预注册与结果

> 2026-07-02。动机：实验B证明"状态门+动量择强底仓"双窗口成立（唯一通过的进攻部件）。
> 本实验做它的最小外推：**同一机制、同一参数，只把择强池从 3 个宽基换成 10 个中证全指一级行业指数**，
> 检验"更细颗粒度的动量选择是否更好"。除池子外不改任何东西、不扫参。

## 预注册设计（先于跑数写定）

| 要素 | 规则 | 备注 |
|---|---|---|
| 择强池 | 中证全指一级行业指数 10 个：000986 能源 / 000987 材料 / 000988 工业 / 000989 可选消费 / 000990 主要消费 / 000991 医药卫生 / 000992 金融地产 / 000993 信息技术 / 000994 电信业务 / 000995 公用事业（.SH） | 历史覆盖两窗口全程；多数有对应行业ETF，与实验B"科创50早段以指数近似"同一先例 |
| 择强规则 | 每 5 个交易日按近 20 日涨幅持有最强 **1** 个 | 与 strong3 完全一致 |
| 初始持仓 | 窗口第 1 个可执行日按前一日动量直接择强（strong3 是从沪深300起步，行业池无自然缺省，取动量领先者） | 唯一与 strong3 的机制差异，预注册 |
| 档位→目标权重 | 60/40/20/0 档 → 50%/30%/10%/0% | 照搬 |
| 再平衡带 / 成本 | 偏离>总资产5%才动；每边 0.03% | 照搬 |
| 风控联动 | 回撤≤-8% 降一档；≤-15% 随熔断清仓停做 | 照搬 |
| 卫星层 | 手册规则完全不动 | 照搬 |
| 运行 | 两窗口 × (含卫星 / --nosat 归因) 共 4 次 | 缓存命中 |

**采纳判据（预注册）**：与现任 base-strong3（含卫星）相比——样本内(2024-06~2026-06)区间总收益提高、且样本外(2019-2023)亏损收窄，**两窗口同向改善**才采纳；任一窗口最大回撤恶化超过 5pp 即否决。不满足则维持 strong3，本实验按"已否定"归档。

**基线（实验B已测）**：
- base-strong3 含卫星：样本内 +46.7% / MDD -11.5% / Sharpe 1.15；样本外 -20.3% / -29.5% / -0.41
- 纯底仓 strong3：样本内 +34.0% / -8.4%；样本外 -10.5% / -20.2%

## 结果（2026-07-02 跑毕）——**否决 ❌，维持 strong3**

| 配置 | 2024–2026 样本内 | 2019–2023 样本外 |
|---|---|---|
| 卫星 + 底仓 strong3（现任基线） | +46.7% / MDD -11.5% / Sharpe 1.15 | -20.3% / -29.5% / -0.41 |
| **卫星 + 底仓 strongsec** | **+56.0% / -11.0% / 1.40**（99笔，平均R 0.209，换标的21次） | **-28.6% / -36.2% / -0.73**（197笔，熔断3次：20200724/20210429/20230413，换标的52次） |
| 仅底仓 strong3（归因基线） | +34.0% / -8.4% / 1.13 | -10.5% / -20.2% / -0.32 |
| 仅底仓 strongsec（归因） | +40.5% / -6.8% / 1.55（平均仓位21.5%） | -12.9% / -21.7% / -0.39（平均仓位12.5%） |

**判定**：样本内改善（+9.3pp）、样本外恶化（-8.3pp，且MDD恶化6.7pp>5pp红线）→ **两窗口方向相反，按预注册判据否决**。

**归因**：
- 纯底仓对比纯底仓方向相同（样本内+6.5pp / 样本外-2.4pp）——分歧来自底仓本身，非卫星交互；卫星在样本外的拖累叠加放大了差距。
- 持仓分布解释了机制：样本内 289 个持仓日中 电信业务94+信息技术56 = 52% 在 AI 主线上，行业颗粒度成功把"择强"对准了时代主线 → 跑赢宽基择强；样本外 530 个持仓日摊在全部 10 个行业上（最多的信息技术也只占 20%），52 次换标的说明 20 日动量在 2019–2023 的行业快轮动里被反复打脸，换手成本+追高割低把宽基层还能拿住的 beta 磨掉了。
- 结论与主报告"时代特异"发现一致：**行业层动量放大了时代暴露——主线时代放大收益，轮动时代放大损耗**。宽基层（strong3）颗粒度更钝，反而更稳健。

**处置**：不合入手册；`--base=strongsec` 代码保留在 portfolio_backtest.py 供日后复查；本文档归档为已否定实验。若未来前向阶段确认"持续主线时代"特征，可作为观察项重新评估（需重新预注册）。

## 诚实限制

- 行业指数不可直接交易；实盘需映射行业ETF，存在跟踪误差、部分行业早年无ETF。
- 10 个一级行业颗粒度仍然很粗（"信息技术"内部分化大），本实验只回答"行业层动量是否优于宽基层"，不回答最优颗粒度——那需要扫参，违反纪律。
- 初始持仓规则与 strong3 有一处机制差异（见上表），已预注册。
