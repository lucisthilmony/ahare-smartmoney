# 实验D：红利防守腿（"熊市不如吃股息"）· 预注册与结果

> 2026-07-02。动机：实验B/C确认底仓alpha主要是"顺势吃beta"，且2024-10后的alpha来源于AI牛市；
> 用户判断"大行情判断至关重要，整体熊市不如买银行吃股息"。本实验把这句话变成可检验命题：
> **底仓在防守/空仓档不回现金，而是停泊到红利资产**。只复用已验证的状态门做进攻/防守切换，不引入新预测。

## 预注册设计（先于跑数写定）

| 要素 | 规则 | 备注 |
|---|---|---|
| 进攻腿 | 与 strong3 完全一致（沪深300/创业板指/科创50，每5日按20日动量择强），目标权重=档位表 50/30/10/0% | 一字不改 |
| 防守腿 | 中证红利**全收益** H00922.CSI，目标权重 = **50% − 进攻腿目标**（60档0% / 40档20% / 20档40% / 0档50%） | 单一公式，无新自由参数；"总底仓恒50%，进攻缩出来的部分停泊红利" |
| 再平衡 / 成本 | 每腿各自 5% 偏离带；每边 0.03% | 照搬 |
| 风控联动 | 回撤≤-8% 降档（进攻缩、防守增——这正是被检验的假设本身）；≤-15% 熔断两腿全清、停做期两腿目标=0 | 照搬 |
| 卫星层 | 手册规则完全不动 | 照搬 |
| 运行 | 两窗口 × (含卫星 / --nosat 归因) 共 4 次 | 缓存命中 |

**采纳判据（预注册）**：与现任 base-strong3（含卫星）相比——两窗口区间总收益同向改善才采纳；任一窗口最大回撤恶化超过 5pp 即否决。

**基线（实验B已测）**：
- base-strong3 含卫星：样本内(2024-06~2026-06) +46.7% / MDD -11.5% / Sharpe 1.15；样本外(2019-2023) -20.3% / -29.5% / -0.41
- 纯底仓 strong3：样本内 +34.0% / -8.4%；样本外 -10.5% / -20.2%

## 结果（2026-07-02 跑毕）——**否决 ❌，维持 strong3；但防守腿是首个样本外为正的底仓配置**

| 配置 | 2024–2026 样本内 | 2019–2023 样本外 |
|---|---|---|
| 卫星 + 底仓 strong3（现任基线） | +46.7% / MDD -11.5% / Sharpe 1.15 | -20.3% / -29.5% / -0.41 |
| **卫星 + 底仓 strong3div** | **+40.1% / -11.9% / 1.00**（98笔，平均R 0.155，平均红利腿30.6%） | **-15.2% / -28.6% / -0.19**（205笔，平均红利腿35.4%） |
| 仅底仓 strong3（归因基线） | +34.0% / -8.4% / 1.13 | -10.5% / -20.2% / -0.32 |
| **仅底仓 strong3div（归因）** | +28.6% / -11.5% / 0.92 | **+14.9% / -13.9% / +0.32**（同期沪深300 +15.5%但回撤-43.2%） |

**判定**：样本外改善（+5.1pp）、样本内恶化（-6.6pp）→ 两窗口方向相反，按预注册判据**否决**。

**归因与教训**：
- 红利防守腿把纯底仓样本外从 -10.5% 拉到 **+14.9%**——五年样本外首个为正的配置，且回撤只有沪深300买入持有的1/3。"熊市不如吃股息"在底仓层面成立。
- 代价是牛市保险费：样本内纯底仓少赚5.4pp、组合少赚6.6pp（红利腿平均占30%仓位但2024-2026跑输AI主线）。
- **规则层面的发现**：本判据（双窗口总收益同向改善）在结构上会否决一切保险型部件——保险的定义就是"好时代付费、坏时代理赔"。这不是本实验设计错误，而是判据的已知边界；若前向阶段确认需要防守腿，应重新预注册一个风险调整口径（如双窗口Sharpe或"每1%回撤换取的收益"）再评估，不得回头改本实验判据。
- 样本外"含卫星 -15.2% vs 纯底仓 +14.9%"（差30pp）再次独立确认：坏时代的亏损主体是卫星层，与实验B结论一致。

**处置**：不合入手册；`--base=strong3div` 代码保留；本文档归档。注意：本实验与实验B/C同用旧股票池口径（002/003被漏，见下一节修正记录），新口径基线重跑后如需引用请以新数字为准。

## 诚实限制

- 用全收益指数记账（含股息再投资），实盘对应红利ETF（如 515080 / 510880），有管理费(约0.5%/年)与跟踪误差，未建模。
- 防守腿在 -8% 回撤降档时会**加**红利仓位——若红利与市场同跌（系统性崩盘），先由 -15% 熔断兜底；该行为是假设的一部分，不是bug。
- 空仓档持有 50% 红利意味着"空仓"不再是零敞口，心理与手册§3的"空仓"语义需要区分：卫星空仓 ≠ 账户空仓。
