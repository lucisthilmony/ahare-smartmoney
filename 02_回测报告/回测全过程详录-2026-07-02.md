## 0. 起因：代码 Review 发现的问题

对 `数据助手/` 代码与《零基础操作手册 v6.1》交叉审查，发现旧回测（`backtest_report.md`，2026-06-21）存在以下影响可信度的问题：

| # | 问题 | 影响 |
|---|---|---|
| 1 | **Tushare 路径未复权**：`daily` 接口是不复权价，所有均线、涨停判定(ret≥9.7%)、红肥绿瘦、每笔收益都被除权除息污染（一次 10派5 或高送转被当成真实暴跌）。手册 §13 自己要求前复权；AKShare 兜底路径却用了 qfq，两路口径不一致 | 回测所有数字的地基 |
| 2 | **出场成交偏乐观**：手册规则"收盘出信号→次日开盘卖"，旧回测按信号当日收盘价成交，吃不到隔夜低开；同日 high≥2R 目标且 close<止损时先按目标卖半 | 系统性高估期望 |
| 3 | **资金曲线是逐笔 R 简单串联**：每天 top3、平均持有 7 天 ≈ 最多 21 个并发仓，违反手册"最多持 2–3 只"；-46.7% 回撤早已触发手册 15% 熔断；未应用 TOP_SECTORS 主线门；用的还是 8日/MA5 旧出场 | 头条数字 +162.5% 不可实现 |
| 4 | 回测缺次新股过滤；ST 用当前股票名回溯（轻微前视）；创业板涨停阈值未按 2020-08-24 注册制分段 | 样本污染（小） |
| 5 | 回测打分与实盘不同源：`score_candidate` 未传 `amt20_yi`（容量微调不生效）、未加核心主线分 | 分档结论轻微失真 |
| 6 | 其他：`score_market` 的 ma20=None 边界 TypeError；`_ts_query` 无限流重试 | 稳健性 |

据此确定三件事：**① 修正口径重跑近两年；② 写组合级回测（按手册规则真实执行）；③ 冻结参数跑 2019–2023 样本外。**

## 1. 代码修正明细（全部已合入 `数据助手/`）

### 1.1 pipeline.py（实盘管线同步受益）
- 新增 `fetch_adj_factors(dates)`：按交易日批量拉全市场 `adj_factor`。
- 新增 `apply_qfq(panel, factors)`：前复权，锚定各股窗口内最新一天（最后一根K线 = 真实现价，实盘显示的止损价/MA10 直接可用）；`open/high/low/close × (factor/最新factor)`，`vol` 反向调整保证跨送转可比，`amount` 不动。
- `limit_up_thr(board, date)`：创业板 2020-08-24 前按 10cm（9.7%）判涨停。
- `screen_one` / `score_candidate` 的涨停判定改为按当日规则（逐行取日期）。
- `_ts_query` 加 5 次重试：限流消息（"每分钟/频率"）等 25s 重试；网络抖动退避重试。
- 修复 `hs.get("ma20", 0)` 在键存在但值为 None 时的 TypeError。
- `build_with_tushare` 拉完日线后统一做 qfq（实盘每日刷新多花约 1 分钟）。

### 1.2 backtest.py（逐笔信号回测 v2）
- 支持命令行窗口：`backtest.py [START_YYYYMMDD] [END_YYYYMMDD]`；缓存文件按窗口命名 `.backtest_cache_qfq_<start>_<end>.pkl`；报告文件带 tag（如 `backtest_report_qfq_2019-2023.md`）。旧报告/旧缓存原样保留。
- `fetch_all`：拉日线同时拉复权因子；先留 `close_raw`（价格上下限 4–80 元过滤必须用当时真实价，复权价会失真），再整体 qfq。
- `simulate()` 出场改次日开盘：止损/破均线在信号**次日开盘价**成交（信号日是最后一根K线则按当日收盘截尾）；时间止损仍按当日收盘（与手册一致）。
- 新增 `stop_mode="intraday"` 变体（实验A用）：当日最低价≤止损价即按 `min(开盘, 止损价)` 成交；同日与 2R 冲突保守地先算止损。
- 重构出 `daily_candidates()` 生成器（与组合级回测共用，保证同源）：内含次新过滤（上市<60交易日≈96自然日）、板块门、行业门、`score_candidate` 补传 `amt20_yi`、核心主线加分后重评级。
- `live_gate()`：实盘 config 的主线门（TOP_SECTORS=5 / CORE_THEMES 排名≤10）。逐笔分析层不加此门（便于对照），组合级加。

### 1.3 portfolio_backtest.py（新增，组合级回测）
事件驱动，逐日执行手册全部约束：

| 环节 | 规则（出处） |
|---|---|
| 市场状态 | §3 四项打分→档位，总仓位上限 60/40/20/0%；板块状态门（创业板指/科创50 vs 各自MA20）；一票否决 |
| 候选 | §4 全部筛选 + 实盘主线门（TOP_SECTORS=5，核心主线排名≤10 保留）+ 评分排序 |
| 入场 | §5 次日尾盘（≈收盘）成交；高开超阈值（主板4%/20cm 7%）放弃；每天最多新开 2 笔 |
| 仓位 | §6 R=总资金×0.75% 倒推股数；单票上限 主板20%/20cm 12%；20cm 合计≤30%；同行业（主题）合计≤30%；最多同时持 3 只；现金约束 |
| 出场 | §7 采纳版 15日/破MA10：2R 盘中触价卖半（限价假设）；止损收盘确认→次日开盘卖；卖半后收盘破 MA10→次日开盘卖；第15日收盘时间止损 |
| T+1 | 入场当日不卖 |
| 熔断 | §6.7 回撤 8%→R 减半+档位降一档；回撤 15%→次日全清、停做 20 交易日、重启后以当前净值为新高点基准（手册未细化，属本脚本假设） |
| 成本 | 佣金万2.5（最低5元/笔）+ 印花税卖出 0.05% + 滑点每边 主板0.1%/20cm 0.2% |
| 其他 | 停牌顺延卖出（与实盘一致）；期末强制平仓计入 |

用法：`./.venv/bin/python portfolio_backtest.py [START] [END] [--base=hs300|strong3] [--nosat]`

## 4. 假设检验：主线稳定性开关（结果：否定）

**假设**：样本外失效是因为 2019–2023 缺少持续主线；加开机条件"当日第1强板块，近10个交易日中排名≤5的天数≥8"能否关掉坏年份、保留好年份？（定义预注册，不扫参）

**方法**：用两个窗口的缓存重算每日行业等权合成指数 20 日涨幅排名 → 每日算第1强板块的10日稳定度 → 与逐笔交易表按决策日合并 → 分桶看平均R。

**结果**（仅Top5主线候选）：

| 第1主线近10日稳定度 | 2019–2023 样本外 | 2024–2026 样本内 |
|---|---|---|
| 0–5 天（轮动/新主线） | -0.328（369笔） | +0.358（350笔） |
| 6–7 天 | -0.182（195笔） | +0.038（226笔） |
| 8–10 天（主线稳定） | **-0.232**（742笔） | +0.296（1157笔） |
| 主线稳定天数占比 | 47% | 53% |

**结论：假设不成立。** 2019–2023 有近一半时间主线是稳定的（半导体、新能源等大主线真实存在），但"稳定主线的缩量回踩买入"照样负期望；2024–2026 连轮动期都是正的。**失效是"时代特异"而非"可观测行情状态特异"**——简单开关无法把两个时代区分开。这排除了"加聪明择时开关"的改进路线。

## 5. 实验A：止损改盘中触价条件单（结果：不采纳 ❌）

**设计**：同一批候选、同一入场与盈利端，只换止损成交方式。现状=收盘确认→次日开盘卖；变体=盘中触价（当日 low≤止损价即按 `min(开盘,止损价)` 成交，同日与2R冲突保守先算止损）。手册 §7 本允许触价条件单。动机：组合级止损单平均 -1.24R，超出 -1R 的是隔夜跳空损耗。
**判定标准（预注册）**：两窗口同向改善才采纳。脚本：`数据助手/experiment_stop_mode.py`；明细：`experiment_stop_mode.md`。

| 窗口 · 出场结构 | 收盘确认 | 盘中触价 | 方向 |
|---|---|---|---|
| 2019–2023 · 8日/MA5 | -0.189 | -0.178 | 略好 |
| 2019–2023 · 15日/MA10 | -0.250 | -0.219 | 略好 |
| 2024–2026 · 8日/MA5 | **0.084** | 0.052 | **变差** |
| 2024–2026 · 15日/MA10 | **0.139** | 0.102 | **变差** |

（Top5主线子集方向相同。触价胜率两窗均降 3–4 个百分点。）

**判定：两窗口方向相反 → 不采纳。** 触价在弱势时代少亏一点，但在系统真正开机的强势时代大量误杀"盘中扎针、收盘收回"的票。**手册现行"收盘确认→次日开盘卖"被验证是对的。**

## 6. 实验B：ETF底仓层 / 核心-卫星（结果：strong3 通过 ✅）

**设计原则**：只用已被样本外验证有效的部件（状态门），不引入新预测；参数预注册不扫参。

| 要素 | 规则 |
|---|---|
| 标的池 | 沪深300 / 创业板指 / 科创50（实盘对应 510300 / 159915 / 588000） |
| 择强 | `strong3`：每 5 个交易日按近 20 日涨幅持有最强者；对照组 `hs300`：固定沪深300 |
| 仓位 | 前一日状态档位 → 底仓目标权重：进攻 50% / 标准 30% / 防守 10% / 空仓 0% |
| 再平衡 | 目标与实际偏离 > 总资产 5% 才动；换标的即调 |
| 风控联动 | 回撤≤-8% 底仓目标降一档（随 R 减半）；≤-15% 随熔断清仓停做 |
| 成本 | ETF 每边 0.03% |
| 卫星层 | 完全不动（手册全部规则），底仓先用现金、卫星用剩余 |

**结果总表**：

| 配置 | 2024–2026 样本内 | 2019–2023 样本外 | 判定 |
|---|---|---|---|
| 仅卫星（现状） | +12.7% / MDD -8.0% / Sharpe 0.66 | -29.9% / -30.7% / -1.28 | 基线 |
| 卫星 + 底仓 hs300 | +15.9% / -10.7% / 0.69 | -30.1% / **-35.3%** / -0.80（熔断3次） | ❌ 样本外更差 |
| **卫星 + 底仓 strong3** | **+46.7% / -11.5% / 1.15**（99笔，平均R 0.210） | **-20.3% / -29.5% / -0.41**（熔断4次） | ✅ 双窗口同向改善 |
| 仅底仓 strong3（归因） | +34.0% / -8.4% / 1.13 | -10.5% / -20.2% / -0.32（熔断1次） | 归因基线 |
| 沪深300 买入持有 | +40.4% / -15.7% | +15.5% / **-43.2%** | 基准 |

**归因**：样本内收益差距主要是 beta——底仓平均仓位仅 ~21% 就拿到 +34%，叠加卫星到 +46.7% 跑赢沪深300 且回撤只有基准的 73%。固定 hs300 不合格 → **动量择强是必要成分**。样本外仍为负：底仓自己 -10.5%（状态门在轮动市被反复扫），卫星再拖约 -10pp——**底仓解决"好行情吃不满"，解决不了"坏时代卫星失血"**（后者只能靠前向失效判据兜底）。

**底仓的性格**：防守型仓位调节器——熊年躲得极好（2022 +1.0% vs 基准 -21.3%），代价是 V 型反转必然踏空（2019 只吃到零头、2020 被疫情反转+7月脉冲来回扫成负并触发一次熔断）。按"每承受 1% 回撤换多少收益"两窗口都优于买入持有；按绝对收益样本外跑输持有 26pp。**定位：不是"跑赢指数的策略"，而是"用踏空换回撤保护的指数择时"**，适合回撤容忍度低的资金。

**诚实提醒**：strong3 是预注册标准下二选一的胜者，判定窗口即这两段 → 按"候选采纳"处理，前向记账与现状并行考核；50/30/10/0% 与"每5日/20日动量"参数冻结不再调。实盘 ETF 有跟踪误差/折溢价；科创50 ETF 2020 年底才成立，样本外早段以指数近似。

## 7. 总结论

1. **口径修正不改样本内结论**（0.081→0.084），旧结论非数据错误。
2. **旧资金曲线 +162.5% 不可实现**；真实执行近两年 +12.7%、回撤 -8.0%、跑输沪深300 28pp。
3. **样本外全面失效且反向**：五年逐笔 -0.189R 年年为负；全部 v5.x 增强反向；评分成反向指标。失效为时代特异，简单开关（含"主线稳定性"）无法识别。
4. **跨时代成立的只有两样**：风控框架（状态门+R定仓+熔断）与出场结构（2R卖半/跌破MA10 的单子两窗皆大赢，+1.2~2.2R）。
5. **实验A（触价止损）否决**——现行收盘确认规则正确；**实验B（strong3底仓）通过双窗口判定**——样本内 +46.7% 跑赢指数，样本外亏损收窄 10pp。
6. **策略价值重定位**：作为选股赚钱机器未被证明；作为"风控骨架 + 底仓引擎 + 训练装置"成立。建议底仓层升主力、个股波段降为小资金学习卫星、失效判据（如滚动60笔期望<0→降半仓/停机）写进手册 §9 机械执行。
