# 回测修正与样本外验证 · 总结（2026-07-02）

> 本次做了三件事：① 修正回测的数据与成交口径并重跑近两年；② 新增"组合级回测"（按手册的资金/仓位/熔断规则真实执行）；③ 用**冻结参数**跑 2019–2023 样本外。
> 一句话结论：**修正口径没有推翻样本内结论，但 2019–2023 样本外全面失效且反向——目前这套系统的正期望只在 2024–2026 这段行情里成立。**

---

## 一、改了什么（代码，均已合入 `数据助手/`）

1. **前复权**（pipeline.py + backtest.py）：Tushare 路径此前用不复权价，除权除息被当成真实涨跌，污染均线/涨停判定/每笔收益。现按 `adj_factor` 做前复权（锚定窗口末，最后一根K线=真实现价），成交量反向调整；价格上下限过滤(4–80元)保留真实价判断。实盘扫描与回测同改。
2. **出场成交口径**（backtest.py）：手册规则是"收盘出信号→**次日开盘**卖"，旧回测按信号当日收盘成交、吃不到隔夜低开，系统性偏乐观。现改为止损/破均线按信号次日开盘成交（时间止损仍按当日收盘，与手册一致）。
3. **回测与实盘打分完全同源**：回测补传容量微调(amt20)、加核心主线加分后重评级；补上次新股过滤（上市<60交易日）；创业板涨停阈值按当日规则（2020-08-24 注册制前 10cm）。
4. **新增 `portfolio_backtest.py`（组合级回测）**：事件驱动，执行手册全部约束——状态档位仓位上限 60/40/20/0%、最多持3只、每日最多开2笔、单票20%/12%、20cm合计≤30%、同主题≤30%、T+1、回撤8%→R减半+降档、回撤15%→清仓停做20日、逐笔佣金/印花税/滑点。用法：`./.venv/bin/python portfolio_backtest.py [START] [END]`。
5. 其他顺手修复：`_ts_query` 加限流/网络重试；`score_market` 的 ma20=None 边界 TypeError。

旧的 `backtest_report.md`（2026-06-21 版）与旧缓存**原样保留**作为历史基线；新报告均带 `qfq_` 前缀。两个窗口的数据缓存共 ~0.7GB 在 `数据助手/.backtest_cache_qfq_*.pkl`，不想让 OneDrive 同步可删（重拉约各 10–25 分钟）。

## 四、怎么解读（诚实版）

1. 这未必全是"过拟合"：2019–2023 是快轮动/无持续主线的市场，2024–2026 是 AI 单主线长坡。**但两种解释对操作的含义相同——本系统的正期望依赖"当前行情结构延续"，不是普适规律。**"抱对趋势>一切"应降级为"2024–2026 行情下成立"。
2. 手册 v5.4 的判断（停止样本内调参、转前向验证）被本次验证**完全证实**，而且比预想更严重：不只是"参数临界"，是整个增强层都行情特异。
3. 值得肯定的：状态门+仓位约束真的把样本外亏损控制在 -30%（对比逐笔串联 -93%），熔断触发了 2 次且有效；"先活下来"这半边是work的。
4. 建议下一步（按优先级）：
   - **给前向验证设失效判据**：例如"滚动 60 笔期望 < 0 或滚动回撤 > 10% → 停用回真钱模拟"，写进手册 §9。
   - **加一个"行情结构开关"再验证**：本策略只在"存在持续主线"的月份开机（如 Top1 板块 20 日排名稳定性、主线持续天数），2019–2023 大部分时间应自动休眠——这是把"行情特异"变成显式规则，而不是暗含假设。注意：这本身又是一次样本内设计，必须再走一遍样本外/前向流程。
   - 手册 §0/§4 中"回测证明""最大Alpha来源"等表述加上样本外警示，避免未来的自己被旧结论误导。

## 附:"主线稳定性开关"假设验证(2026-07-02,补充)

假设:样本外失效是因为 2019–2023 缺少持续主线;若加"第1强板块近10日中排名≤5的天数≥8"作为开机条件,能否关掉坏年份、保留好年份?

结果(仅Top5主线候选的平均R,按主线稳定度分桶):

| 主线稳定度(近10日) | 2019–2023 样本外 | 2024–2026 样本内 |
|---|---|---|
| 0–5 天(轮动/新主线) | -0.328 (369笔) | +0.358 (350笔) |
| 6–7 天 | -0.182 (195笔) | +0.038 (226笔) |
| 8–10 天(主线稳定) | -0.232 (742笔) | +0.296 (1157笔) |

**结论:假设不成立。** 2019–2023 主线稳定期占比 47%,但稳定主线的回踩买入照样负期望;2024–2026 连轮动期都是正的。失效是"时代特异"而非"可观测行情状态特异"——无法用这个开关(以及大概率任何同类简单开关)把两个时代区分开。改进方向应转向:制度化的前向失效判据、beta/alpha 分层、降低执行损耗,而不是更聪明的择时开关。

## 附2:改进实验 A/B 结果(2026-07-02 下午,补充)

### 实验A · 止损改盘中触价条件单 —— ❌ 不采纳(双窗口方向相反)

| 窗口 | 8日/MA5 收盘确认 | 8日/MA5 触价 | 15日/MA10 收盘确认 | 15日/MA10 触价 |
|---|---|---|---|---|
| 2019–2023 样本外 | -0.189 | -0.178(略好) | -0.250 | -0.219(略好) |
| 2024–2026 样本内 | **0.084** | 0.052(差) | **0.139** | 0.102(差) |

触价在弱势时代少亏一点,但在系统真正开机的强势时代大量误杀"盘中扎针、收盘收回"的票。
**结论:手册现行"收盘确认→次日开盘卖"是对的,保持不变。**(明细见 `experiment_stop_mode.md`)

### 实验B · ETF底仓层(核心-卫星) —— ✅ strong3 变体通过双窗口判定

设计(预注册):状态档位→底仓目标 50/30/10/0%;卫星层(个股波段)完全不动;ETF成本每边0.03%。
两个变体:`hs300`=固定沪深300;`strong3`=沪深300/创业板指/科创50 每5日按20日动量择强。

| 配置 | 2024–2026(样本内) | 2019–2023(样本外) |
|---|---|---|
| 仅卫星(现状) | +12.7% / MDD -8.0% / Sharpe 0.66 | -29.9% / MDD -30.7% |
| 卫星 + 底仓hs300 | +15.9% / -10.7% | -30.1% / -35.3% ❌ |
| **卫星 + 底仓strong3** | **+46.7% / -11.5% / Sharpe 1.15** | **-20.3% / -29.5%** ✅ 双窗口同向改善 |
| 仅底仓strong3(归因基线) | +34.0% / -8.4% / Sharpe 1.13 | -10.5% / -20.2% |
| 沪深300 买入持有 | +40.4% | +15.5% |

**归因解读:**
- 样本内的收益差距主要是 beta:状态门管理的三指数动量底仓,平均仓位仅约21%就拿到+34%,叠加卫星到+46.7%、跑赢沪深300且回撤只有-11.5%。
- 固定hs300底仓不合格:样本外没改善、回撤反而加深。**动量择强(strong3)是必要成分**。
- 样本外仍为负:底仓自己 -10.5%(状态门在轮动市被反复扫),卫星再拖 -10pp。**底仓层解决"好行情吃不满"的问题,解决不了"坏时代卫星失血"的问题**——后者仍然只能靠前向失效判据(推荐4)兜底。

**诚实提醒:** strong3 是二选一里胜出的那个,且判定窗口就是这两段——虽然标准是预注册的,仍建议:①把它当"候选采纳",在前向验证里与现状并行记账;②底仓目标 50/30/10/0% 与"每5日/20日动量"参数**冻结,不再调**。
