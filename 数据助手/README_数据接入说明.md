# 数据接入说明（Mac）

把《A股短线波段操作助手》从"手动填数"升级为"盘后自动选股 + 盘中实时校验"。**不自动下单，下单永远手动。**

## 它是怎么工作的

```
盘后：pipeline.py ──拉数据→算指标→市场状态打分(§3)→选股(§4)──→ 写 data.js
                                                                    ↓
你：浏览器打开 http://127.0.0.1:8787/  ←─ server.py 本地服务 ─→ /api/eod 候选池
                                                              └─→ /api/quote 盘中实时(新浪)
```

- 数据源：**Tushare Pro**（推荐，全市场扫描）；没配 token 时自动退回 **AKShare**（免费，仅扫 `config.py` 里的自选清单）。
- 盘中实时：新浪 L1（服务端抓取，绕开浏览器跨域）。
- 一切数据只在你本机，不上传。

## 一次性设置（约 10 分钟，丈夫操作）

### 第 1 步：装 Python3
终端运行 `python3 --version`。若没有，去 https://www.python.org/downloads/macos/ 装最新版（或 `brew install python`）。

### 第 2 步（推荐）：拿 Tushare token
1. 注册 https://tushare.pro → 登录 → 「个人主页」复制 **token**。
2. 全市场扫描建议积分 ≥ 5000（官方约 500 元/5000积分；积分越高频率越高）。积分低也能跑，只是慢、可能偶尔超频。
3. 打开 `数据助手/config.py`，把 token 填到 `TUSHARE_TOKEN = "这里"`。
> 不想现在花钱？跳过本步，直接用 AKShare 免费起步：把想盯的票填进 `config.py` 的 `WATCHLIST`，其余照常。

### 第 3 步：给两个 .command 加可执行权限
终端里（把文件夹拖进终端可自动补路径）：
```bash
cd "/Users/cuiyong/Library/CloudStorage/OneDrive-个人/CoworkSpace/A股策略蒸馏/数据助手"
chmod +x 启动数据服务.command 盘后刷新数据.command
```

### 第 4 步：首次启动
双击 **`启动数据服务.command`**。首次会自动建虚拟环境并装依赖（2–5 分钟），完成后浏览器会自动打开 `http://127.0.0.1:8787/`。
> 若双击提示"无法打开"，右键 → 打开 → 仍要打开；或在系统设置→隐私与安全性里允许。

## 每天怎么用

1. **盘后（15:00 后）**：在页面「📡 数据」点 **「盘后刷新数据」**（或双击 `盘后刷新数据.command`）。几分钟后「今日市场状态」和「今日候选池」自动出现。
2. **看候选池**：每只票点 **「带入算仓」** → 自动跳到「🧮 算仓」并填好板块/现价/MA10 → 得到股数、止损、2R目标。
3. **次日尾盘（14:30–14:50）**：在「📡 数据 → 盘中实时校验」输代码，看 **高开%**（主板>4%/20cm>7% 当天放弃）和现价是否回踩不破 MA10；满足就按算仓结果下单。
4. **平仓后**：在「📒 日志」记一笔。

> 页面开着服务才有实时；只想离线看候选池，双击 `.html` 也能读最近一次的 `data.js`（无实时）。

## 候选股打分（0–100，已按分排序）

通过六项硬筛选的候选股，会再按强弱打一个 0–100 分（「📡 数据」里已按分从高到低排，鼠标悬停看分项）：

| 维度 | 权重 | 看什么 |
|---|---|---|
| 趋势 | 15 | MA20 斜率 + 多头排列（MA10>MA20>MA60） |
| 主线 | 15 | 所属行业指数高于其 MA20 的幅度（板块越强越高） |
| 相对强度 | 15 | 个股近20日跑赢沪深300的幅度（强于大盘，尾盘选股精华） |
| 资金 | 15 | 近期涨停/放量大阳的强度 × 新近度 |
| 回踩 | 20 | 越贴近 MA10、越缩量越好 |
| 红绿 | 10 | 阳线实体 / 阴线实体（红肥绿瘦） |
| 风险 | 10 | 不追过度乖离(防反转) + 止损相对紧 |

表里还会显示 **RS**（相对强度%）、**换手率**、**流通市值** 三个参考列（尾盘选股法偏好换手 5–10%、流通 50–200 亿，可据此再做人工取舍）。

等级：**A ≥ 75 强、B 60–74 中、C < 60 偏弱**。分高=更强、更优先，**但仍要你自己过买点三道门、按算仓定仓**。打分只排优先级，不替代纪律，更不是买入指令。

## 局限与风险（务必知道）

- **AKShare 免费源**稳定性/延迟无保障，源站改版接口会临时失效；认真做就上 Tushare。
- **盘中实时**为新浪 L1，非交易时段或被限流时可能取不到——取不到就回到"尾盘人工看盘"，不影响策略。
- **行业/主线门**用全市场合成行业指数近似；与券商口径不完全一致，作过滤够用。
- 自动选出的是"**符合规则的候选**"，**不是买入指令**。是否买、买多少，仍由你按手册和算仓结果决定。
- 分钟级/L2 数据需 Tushare 另行付费，本工具默认不用。
- **本工具不构成投资建议，实盘风险自负。** A股短线为负和博弈，先活下来与守纪律为第一目标。

## 多机环境一致性（2026-07-03）

两台机器经 OneDrive 共享本文件夹的 `.pkl` 缓存。**pandas 版本必须全体一致（锁定 2.3.3）**，
否则 pandas 3.x 写出的 pickle 在 2.3.3 下读不了（StringDtype 序列化不兼容），且 OneDrive 会把
两边的缓存互相覆盖（曾于 2026-07-02 损坏样本外回测缓存，靠"-崔勇的MacBook Pro"冲突副本恢复）。

三层防护（已就位）：
1. `requirements.txt` 锁 `pandas==2.3.3`；
2. `pipeline.py` 导入时版本不符即打警告，写共享缓存前 `assert_cache_write_ok()` 直接拒绝；
3. 新机器/版本漂移时双击 `对齐pandas版本.command` 一键对齐（venv 不可用时自动建本机专用 venv）。

注意：`.venv` 里的二进制不跨机器通用，随 OneDrive 同步本身就是隐患；如再出诡异问题，
优先考虑把 `.venv` 与 `.pkl 缓存`移出同步目录（各机各建）。
