# 上海老太太小红书字幕档案

这是截至2026-07-19该主页可见的20条笔记快照，包括17条视频和3条图文；不包括关联账号、此后新增、删除、私密或登录后仍不可见的内容。

## 主要文件

- `蒸馏报告.md`：核心框架、重复、冲突、营销信号和可实验规则。
- `all_transcripts.md`：20条中文正文合并全文。
- `video_manifest.csv`：笔记ID、日期、时长、标题、来源类型和公开链接。
- `transcripts/`：每条笔记一份纯文本稿。
- `raw_srt/`：48个小红书平台原始SRT，以及1个画面字幕逐帧核对SRT。
- `note_images/`：3条图文笔记的原始图片。
- `note_image_text/`：从原图逐字核对并合并重复分页的中文正文。
- `metadata/`：每条笔记的抓取元数据、字幕轨、图片和视频流信息。
- `fetch_report.md`、`verification_report.md`：抓取与完整性检查结果。
- `fetch_results.jsonl`：机器可读的完整结果。
- `fetch_xhs_subtitles.mjs`、`verify_outputs.mjs`：可复跑的抓取与核验脚本。

## 证据约定

平台有字幕时以 `source` 轨作为中文正文，`zh-CN` 和 `en-US` 轨留作交叉检查。第05条没有平台字幕，正文来自画面内嵌字幕逐帧核对；第16、19、20条是图文，正文来自原图文字。原始平台SRT不做人工修改，因此仍可能保留同音错字。

页面访问令牌属于短期抓取参数，日后重跑可能需要从主页重新取得；稳定身份以 `note_id` 和无令牌公开URL为准。
