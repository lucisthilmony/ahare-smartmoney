## 3. Condensed Frameworks

### 3.1 分歧/一致与辨识度

Source: `160871406`

Core idea: 分歧提供后续买盘转化空间，一致意味着愿意买的人可能已经大多进场。辨识度能吸引资金，但只有具备影响力和带动性的辨识度才可能成为核心。

Reusable rules:

- 下跌分歧要看止跌、缩量、小阳小阴或十字星，以及外部刺激是否可能打破平衡。
- 上涨分歧要看放量换手和筹码重置，而不是只看涨停数量。
- 一致阶段要问：剩余买盘能否接住早期获利盘。
- 辨识度股第二天该强不强，超短就卖。

Main misuse:

- 把所有分歧都当买点。
- 只看形态辨识度，不看板块带动、联动和市场影响。

### 3.2 散户思维与反完美主义

Source: `160871352`

Core idea: 散户常亏在追求完美：想买最低、卖最高，结果卖在起爆前、买在情绪后段。

Reusable rules:

- 主动让利市场，接受卖飞或没吃完整段。
- 强股买点常常反人性；过于舒服的买点往往没有足够边际。
- 找适合自己的优势模型，不要复制别人完整人格。

Main misuse:

- 把盘中每个波动都当作是否完美的评分。
- 因为想卖最高，提前卖掉真正的强趋势。

### 3.3 涅槃重升树干系统

Source: `160871295`

Core idea: 零碎小规律会互相矛盾，必须挂在一个总树干上。树干是赚钱效应、情绪延续、资金吸引和市场阻力最小方向。

Reusable rules:

- 每天评估六层情绪：市场、投机、板块、整体市场、整体投机、整体板块。
- 投机情绪看涨停数、连板数、连板高度、炸板率。
- 市场情绪看指数强度和涨跌比。
- 板块情绪看高度、主升、人气、集体爆发和发酵。
- 不做冷门自以为低风险的重仓机会。

Main misuse:

- 每天总结一堆新规律，上场时全部忘掉。
- 把细分信号放在整体趋势与情绪前面。

### 3.4 陈小群龙头选择

Source: `160871235`

Core idea: 龙头选择不是单一K线，而是大题材、强逻辑、历史新高量、换手、低价空间、指数阶段和市场合力叠加。

Reusable rules:

- 优先持续性大题材和持续发酵逻辑。
- 第一波分歧出现历史高量或明显成交量堆时重点观察。
- 龙头买入可用弱转强、反包超预期、平台突破、次龙头首阴低吸。
- 指数调整末期提前启动的品种更值得重视。

Main misuse:

- 只数板，不看题材和合力。
- 把次龙头首阴当成任何跟风股回调买点。

### 3.5 龙头战法三系统

Source: `160871164`

Core idea: 龙头战法是周期、节奏、主流、地位的动态叠加，不是无脑数板。

Reusable rules:

- 环境与情绪系统决定攻防和仓位。
- 题材系统决定选股方向。
- 技术与形态系统决定具体个股和出击点。
- 打板、半路、低吸、潜伏四种方式都必须围绕主流活跃股。
- 自选股要小，只放真正龙头或候选龙头。

Main misuse:

- 行情不好还接力打板。
- 买到龙头却因小分时抖动卖飞。

### 3.6 炒股养家交易系统

Sources: `160871115`, `160869448`

Core idea: 短线核心是揣摩市场情绪，比较场外潜在买盘和场内潜在卖盘。买机会，卖不确定，胜负交给概率。

Reusable rules:

- 有赚钱效应时做热点；有恐慌效应时做超跌；没有效应时休息。
- 热点分长期主流和短期支流，主流可反复，支流只做爆发。
- 预判只是准备，应变才是交易。
- 忘记成本：假设现在空仓，还会买吗？会买别的就换，会空仓就卖。
- 重仓必须同时满足高胜率和极好盈亏比。

Main misuse:

- 用固定止损止盈替代动态判断。
- 为做T而做T，而不是同一日内重新衡量收益风险。

### 3.7 退学炒股心理纪律

Sources: `160871006`, `160870886`, `160580725`

Core idea: 技术可学，性格控制决定你能不能只做自己真正有把握的点。

Reusable rules:

- 没有目标就不买，瞎买会让自己陷入被动。
- 赚钱后防膨胀，亏钱后防翻本心。
- 错了就纠错，不幻想奇迹资金来救。
- 空仓是看着盘、随时能下单，但选择不做。
- 分仓防连续失败的大回撤。
- 交易对错和盈亏分开，盈利交给市场。

Main misuse:

- 大亏后加钱，而不是反思。
- 卖错后马上追回，做情绪修补。
- 把别人的赚钱当成自己的踏空亏损。

### 3.8 打板隔日预期

Source: `160870949`

Core idea: 打板后能不能赚钱，取决于市场情绪、个股板的硬度、板块队友和竞价承接。

Reusable rules:

- 大环境先看最近涨停票隔日溢价。
- 个股看封板早晚、开板次数、分时硬度。
- 板块看队友开得如何，自己是前排还是后排。
- 弱板想转强，竞价必须放量承接卖盘。
- 换手率不看固定数值，要对比近期量、阶段量、历史量。

Main misuse:

- 后排烂板也按前排强板预期处理。
- 用固定换手率判断好坏。

### 3.9 分时卖点工程

Source: `160870825`

Core idea: 卖在高点靠工程化信号，不靠幻想。

Reusable sell triggers:

- 竞价不及预期。
- 炸板纪律性减仓。
- 分时背离。
- 均线乖离过大。
- 尖角波和盘口衰竭。
- 压力位不过。
- 跌破关键支撑或平盘。
- 原有利润垫被打穿。

Main misuse:

- 利润垫很薄还等二次确认。
- 压力位缩量不过还幻想突破。

### 3.10 抄作业与赚钱效应模仿

Source: `160870733`

Core idea: 超短本质上有模仿扩散，真正要抄的是赚钱效应的传播路径，而不是别人的代码。

Reusable rules:

- 龙头不可总是预测，补涨和模仿更可复制。
- 扩散路径包括题材、名字、代码、图形、分时。
- 朦胧相似阶段边际高，公开对标阶段接盘风险高。
- 量化会加强图形模仿，但一致后也会加速A杀。

Main misuse:

- 看到公开对标后才买。
- 把别人推荐当作抄作业。

### 3.11 92科比三模式

Source: `160870639`

Core idea: 短线投机有三种主模式：主线龙头、补涨、切换/冰点。资金会从亏钱效应处流向新赚钱效应。

Reusable rules:

- 大赚钱效应出现后，研究它会被如何模仿。
- 旧方向出现结构变丑、A字杀、潜伏盘重、溢价消失，就要准备切换。
- 切换要早于大众，晚了就是接盘。
- 20cm等波动变大时，要降低仓位比例。

Main misuse:

- 只看自己账户盈亏，不看市场赚钱/亏钱效应。
- 强行进入不适合自己的风格。

### 3.12 新手十个大坑

Source: `160870476`

Core idea: 新手少亏钱，首先靠避坑。

Reusable rules:

- 利好兑现前已大涨的票，兑现日可能是卖点。
- 连续赚钱不等于悟道，可能只是行情或运气。
- 交流群会放大群体错误。
- 热门技术指标和热门战法会同质化。
- 不加杠杆，不买热点杂毛，不补仓，不抄底。
- 充分理解人性中的自欺、幻想、膨胀、翻本、眼红。

### 3.13 北京炒家：曲线、止损和打板

Sources: `160869983`, `160869924`

Core idea: 北京炒家的核心不是一个神奇买点，而是高频系统中持续剔除错误、弱就出、用机械执行保护曲线。

Reusable rules:

- 高频交易长期不亏已经是高手。
- 先消灭低级错误，曲线只要抬头一点点就能复利。
- 亏损后不要破罐破摔，抛开盈亏只看交易可控性。
- 止损不是固定几个点，走弱就出。
- 新手打板优先回封板、准备板、换手板和板块支撑板。
- 少碰快速秒板、无板块效应板、14:30后偷鸡板。

Main misuse:

- 把止损理解成固定百分比。
- 看见巨量就一律不能打，忽略辨识度和次日弱转强潜力。

### 3.14 心性、空仓和回撤线

Source: `160869867`

Core idea: 技术只是表象，心性才是天花板。心魔、不能空仓和仓位失控是散户的三大障碍。

Reusable rules:

- 每次克制追高、果断止损、看别人涨停不动心，都是一次胜利。
- 空仓不是躺平，是看懂行情但选择不做。
- 账户从高点回撤约10%时进入防守模式，把仓位压到低位。
- 赚钱时别自封股神，亏钱时别自我否定。

Main misuse:

- 把盲目自信当成强大内心。
- 连续止损后放弃系统。

### 3.15 2万哥训练路径

Source: `160869730`

Core idea: 新手不是缺钱，是缺执行力、纪律、模式验证和无效交易剔除。

Reusable path:

- 用小资金训练，不借钱加仓。
- 第一阶段练执行力和交易纪律，买卖不能有心理障碍。
- 第二阶段找自己喜欢且适合的单一模式。
- 第三阶段在单一模式下做到月度成功率约50%。
- 第四阶段分析成功和失败交易，剔除无效交易。
- 第五阶段交易变得无趣后，再谈控制回撤和放大资金。

Main misuse:

- 还没稳定就加钱。
- 用模拟盘训练真实执行力。

### 3.16 陈小群 vs 北京炒家

Source: `160869597`

Core idea: 陈小群和北京炒家代表两种不同超短模型，不能机械互抄。

Reusable distinction:

- 陈小群：龙头合力模型，核心是感知买盘是否枯竭，更依赖体量和盘感。
- 北京炒家：首板跟庄/主力模型，核心是第一板后主力大概率有溢价或自救。
- 两者共同点是极强执行力和适配自身环境。

Main misuse:

- 小资金硬模仿陈小群的大体量盘感。
- 首板不筛强主力、强辨识度，只看第一个涨停。

## 4. Cross-Entry Rule Synthesis

### 4.1 Selection Filters

- 当前主流题材、核心龙头、前排、强辨识度或明确低风险转折。
- 排除低质量跟风杂毛、冷门自嗨股、预期已兑现高位股、庄股/问题股、无板块带动股。
- 强股基因包括近期涨停、放量突破、红肥绿瘦、承接强、分歧不死、回封有效。

### 4.2 Entry Timing

- 分歧买入必须接近转折。
- 弱转强需要竞价或开盘承接验证。
- 打板要看市场情绪、板块效应、封板硬度和队友。
- 半路/低吸/潜伏都只服务主流活跃股，不服务随机幻想。

### 4.3 Exit Discipline

- 不看好就卖，别被成本绑架。
- 竞价不及预期、走弱不能收回、炸板、压力不过、支撑破、利润垫消失都可卖。
- 卖错后只复盘原因，不盲目追回。

### 4.4 Position Management

- 仓位跟胜率、空间、下跌风险、市场情绪和账户状态绑定。
- 回撤触发防守线后降仓，不靠加钱修复系统问题。
- 小资金先证明执行和模式，再放大资金。

### 4.5 Mindset

- 最大敌人是完美主义、踏空焦虑、亏损翻本、盈利膨胀、眼红别人和拒绝认错。
- 空仓是进攻系统的一部分。
- 操作对错和盈亏分开，盈利交给市场。

## 5. Review Questions

1. 今天市场是赚钱效应扩散，还是亏钱效应扩散？
2. 当前主流题材是谁？是否有新切换方向？
3. 我买的是龙头、前排、核心低吸，还是舒服的杂毛？
