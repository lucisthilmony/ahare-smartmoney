# Codex 更高 Alpha 策略研究与回测

生成日期：2026-07-02

## 1. 研读后的核心判断

现有材料的主线很清楚：A 级骨架是市场状态、仓位、止损、纪律；B 级增强是强主线、核心股、买分歧；C 级内容是打板、盘感、重仓单挑，需要隔离。

已有回测也给出一个硬结论：原个股卫星层在 2019-2023 样本外是主要失血源，strong3 底仓负责吃 beta，真正需要提高 alpha 的地方不是再加仓，而是减少卫星层在错误时代和错误形态里的交易。

因此本次不再寻找更刺激的买点，而是把蒸馏里的三句话量化成卫星层开仓闸门：

- 强主线才做。
- 买分歧，不买极端一致。
- 核心趋势可以接力，但避开已极端过热。

## 2. 双窗口逐笔筛查

用已有逐笔信号库筛查字段：板块排名、评分、相对强度 RS、60 日涨幅、20 日日均成交额、交易板块。筛选规则必须同时满足：

- 2024-2026 平均 R > 0。
- 2019-2023 平均 R > 0。
- 两个窗口样本数均不少于 80 笔。

最稳的两类信号：

| 过滤器 | 2024-2026 平均R / 样本 | 2019-2023 平均R / 样本 | 解释 |
|---|---:|---:|---|
| 强主线 + RS>0 + 60日涨幅<0 + 成交额2-5亿 | +0.271 / 109 | +0.184 / 132 | 强主线里的左侧修复/低位回踩 |
| 评分>=75 + 板块排名<=10 + 60日涨幅60-100% + 成交额>=5亿 | +0.262 / 170 | +0.174 / 115 | 已成趋势但未极端过热的中继 |

这两个过滤器合并成 Codex Alpha 卫星层。

## 3. 策略定义

底仓不改：strong3，沪深300 / 创业板指 / 科创50 每 5 日按 20 日动量择强，状态档位控制 50% / 30% / 10% / 0%。

卫星层只允许以下两类候选开仓：

1. 回踩修复型：板块排名 <=5，RS>0，60 日涨幅 <0，20 日日均成交额 2-5 亿。
2. 中继趋势型：评分 >=75，板块排名 <=10，60 日涨幅 60-100%，20 日日均成交额 >=5 亿。

其他组合级规则全部沿用原手册：T+1、最多持 3 只、每日最多开 2 笔、单票上限、20cm 上限、同行业上限、2R 卖半、15 日 / MA10 出场、回撤 8% 降档、回撤 15% 熔断。

## 4. 组合级回测结果

| 策略 | 2024-2026 | 2019-2023 |
|---|---:|---:|
| 原 strong3 + 原卫星 | +43.9% / MDD -12.7% / Sharpe 1.12 | -25.1% / MDD -32.6% / Sharpe -0.49 |
| Codex Alpha + strong3 | **+52.1% / MDD -11.9% / Sharpe 1.35** | **-13.2% / MDD -23.5% / Sharpe -0.28** |
| 改善 | +8.2pp，回撤收窄0.8pp | +11.9pp，回撤收窄9.1pp |

## 5. 结论

Codex Alpha 没有把 2019-2023 扭成正收益，所以不能宣称找到了跨时代稳定正 alpha。

但它显著改善了现任 strong3 组合：

- 2024-2026：收益更高，回撤略低，Sharpe 提高。
- 2019-2023：亏损从 -25.1% 收窄到 -13.2%，最大回撤从 -32.6% 收窄到 -23.5%，熔断次数从 4 次降到 2 次。
- 卫星交易数从样本外 211 笔降到 98 笔，说明改进主要来自“少做坏交易”，而不是更激进。

建议把它列为候选采纳：不替换底仓 strong3，只替换个股卫星层的开仓资格，并进入前向并行记账。正式合入前，建议设前向失效判据：

- 连续 40 笔卫星平均 R < 0，暂停卫星层。
- 组合从阶段高点回撤超过 10%，卫星层降到只允许回踩修复型。
- 若 3 个月内跑输“仅 strong3 底仓”且卫星平均 R < 0，退回仅底仓。
