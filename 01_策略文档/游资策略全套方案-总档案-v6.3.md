## 1. 方案从哪来：三步管线

**① 蒸馏**：800+位游资/短线高手的访谈与教学转录（约190万字，youzi168矩阵+31个框架），提炼为可检验的规则假设。
**② 双窗口验证**：任何规则必须在 2024-06~2026-06（样本内）与 2019-2023（样本外，参数冻结）**两个时代同向改善**才采纳；预注册判据、不扫参、不用结果倒推。
**③ 前向裁决**：回测通过仅获"候选"资格，真正的采纳权在前向实盘/记录数据（当前观察期 2026-07-03 ~ 2026-10-03）。

**方法论的核心发现**（2026-07-02/03，全部有据可查）：
- 个股短线信号普遍**时代特异**——样本内正期望的入场形态，样本外五年全负，且任何可观测状态开关都救不了它；
- 公开数据里的时点/跟随信号（打板溢价、龙虎榜跟随），在可执行口径（T+1、可达性、成本）下**全部为负**——游资的edge存在于公布之前；
- 跨时代存活的只有：**风控框架、出场结构、指数动量择强、防守型硬规则**。整套方案就是围绕这四样搭建的。

## 2. 总架构：两层仓位 + 三道保险丝

```
账户资金
├── 底仓（主引擎，≤50%）── strong3 指数ETF动量择强 × 档位定权重
├── 卫星（训练模块，档位上限内）── §4筛选 → 三道门 → A门 → 执行卡
└── 现金（其余）
保险丝：①失效判据（滚动60笔期望，自动减半/停机）
        ②雷劫规则（10日翻倍+收跌=无条件离场）
        ③回撤熔断（-8%降档减R / -15%清仓停做20日）
```

**定位声明**（手册§0）：卫星层在2019-2023样本外为负期望，其定位是小资金训练装置与本时代进攻模块；底仓层为**候选防守型Beta主仓**——两窗口均未跑赢沪深300总收益，其已证明的价值是回撤保护（风险调整后占优），"能否产生超额总收益"待前向证明。

## 3. 完整规则集（可执行口径，含全部参数）

### 3.1 市场状态与档位（每晚18:30自动打分）
四项各1分：沪深300收盘>MA20；>MA60；两市成交额≥近20日均；**阳线家数>阴线家数**（日内广度，v6.4.1正名；较昨收口径已对照否决）且无涨停股集体大面。
**3-4分=进攻(总仓上限60%) / 2分=标准(40%) / 1分=防守(20%) / 0分=空仓(0%)**；成交额连续3日萎缩→降一档；一票否决（放量破60线/千股普跌/昨涨停股集体大面）→直接空仓。板块门：创业板指/科创50各自须在MA20上方，20cm票才可做。

### 3.2 底仓（strong3，已自动化）
- 标的池：沪深300(510300) / 创业板指(159915) / 科创50(588000)，**只持一只**；
- 择强：每5个交易日一个检查点（相位锚点2024-06-18按交易日mod5，无状态推算），按检查点前一交易日的近20日涨幅持最强者；
- 权重：档位→ 50%/30%/10%/0%；偏离目标超总资产5%才调仓；
- 执行：每天14:40 Discord信号给出标的+权重+换仓/调仓警示，尾盘执行；
- 联动：账户回撤>8%底仓降一档（人工），>15%随熔断清仓停做。

### 3.3 卫星选股（§4筛选 → A门）
硬性池：沪深主板(60/00开头,10cm)+创业板(30,20cm)+科创板(68,20cm)；排除北交所/ST/次新(<60交易日)；价格4-80元；20日日均成交额≥2亿。
§4筛选（全过才候选）：当前主线（板块20日涨幅排名≤5，核心战略主线白名单放宽至≤10+评分加6）；趋势向上（收盘>MA20、MA10>MA20）；近10-20日有涨停或放量大阳（资金参与过）；红肥绿瘦；缩量回踩MA10±3%；无破位。
**A门（v6.3开仓资格，四条同时满足）**：主线排名≤5 且 RS>0（20日跑赢沪深300）且 60日涨幅<0 且 20日日均成交额2-5亿。＝强主线内的低位修复形态。**无A型候选=休息。**

### 3.4 盘中执行（14:40信号 → 尾盘下单）
同日总闸：沪深300≤-2%或成交额<8000亿→×0不买；≤-0.5%或<1万亿→×0.5减半。
三道门（对每只候选实时查）：未破位（距MA10≥-3%）；不追高（距MA10≤+3.5%、当日涨幅未超板块阈4%/7%）；非独跌。
每天最多开2笔、最多同时持3只；竞价高开超阈（主板4%/20cm7%）当天放弃。

### 3.5 仓位与风控
R=总资金×0.75%；股数=R÷(买价−止损价)，主板取整100股/科创≥200股；止损位=参考位(MA10或回踩低点)下方主板5%/20cm8%；单票上限主板20%/20cm12%；20cm合计≤30%；同行业合计≤30%；禁杠杆、禁补仓摊平。
回撤熔断：账户自最高点回撤8%→R减半+档位降一档；15%→全清、停做20交易日、复盘后以当前净值为新基准。

### 3.6 卖出（先到先执行）
1. 止损：收盘跌破止损价→次日开盘卖（收盘确认制——触价条件单已被实验A双窗口否决）。
2. 2R卖半：涨至买价+2×(买价−止损价)→卖一半。
3. 跟踪止盈：剩余仓收盘跌破MA10→次日卖。
4. 时间止损：持满15个交易日→收盘了结。（15日/MA10为回测最优甜区）
5. **雷劫规则（硬性）**：10个交易日累计涨幅≥100%后任一日收跌→次日开盘无条件清仓。
6. 危险信号提前离场：两根未修复阴线/板块被新主线抽血/20cm板块门破位/放量滞涨/早盘10点前明显走弱/利润垫打穿/卖在一致。
7. 卖错不追回。

### 3.7 失效判据（机械执行，凌驾于一切开仓信号）
数据源=根目录交割记录.csv（每平仓一笔记：平仓日期,代码,名称,R倍数,备注）。
近60笔平均R<0 → R×0.5+档位降一档；连续两个检查点（每20笔）均<0 → **卫星层停做**（信号卡自动改发休息），转模拟盘，期望回正自动恢复。不足60笔不启用。

## 6.5 Alpha概率校准账本（2026-07-19评审终判 · 十月按预写规则机械更新）

**评审终判（含PBO/DSR式多重试验折价）**：

| 判断对象 | 评审概率 | Claude副签 |
|---|---|---|
| A门信号库存在较弱但真实的优势 | 35%–45% | 30%–40%（微扰表呈平台状但prior60收紧即翻负，中枢略压低） |
| 现行score-top1排序有增量Alpha | 10%–15% | 同意（两窗相关≈0、低分组历史更优） |
| **当前完整策略原样运行获得稳定净Alpha（2-3年跨风格、费后、相对纯底仓）** | **≈25%[15,35]** | ≈20%[12,30]（2026年7笔-0.417R是最新时代的信号，权重应略高） |
| 按现有纪律继续迭代，1-2年找到可验证Alpha | 40%–50% | 同意 |

**预写更新规则（S vs R前向实验，各≥40笔平仓后裁决）**：
- S−R周聚类95%CI下界>0 → 完整策略概率上调至55%–65%；
- S≈R但两者均优于纯底仓 → "A门有效、评分无效"，删除排序做更简策略（新前向再验）；
- S与R均不行，或行业指数两构造法方向相反 → 概率降至<10%，卫星层降级纯底仓。

**支撑证据快照**（独立审计alpha_validation_report，重放一致性已验证）：2024-2026主动收益3.53%/IR0.89/HAC t=1.35（未显著）；2019-2023主动0.24%/t=0.14；两窗实际入选交易CI均跨0；分年R：2025+0.667(18笔)→2026-0.417(7笔)。

**结论句存档**："系统已很有能力不把噪声当成Alpha，但还没有证明自己能抓到Alpha；值得继续影子验证，不值得因工程完善而扩大真钱风险。"

**项目哲学定稿（2026-07-20，用户手笔，原文存档）**：
> 大资金苦于容量，小资金苦于证据；最后都败给同一个对手——市场比想象中有效。
> 阳光下不是没有Alpha，而是Alpha一旦被阳光照得人人都看见，通常就只剩Beta、拥挤和交易成本了。
> 小资金的真实优势：不必满仓、不必跑赢季度排名；可以长期等一年只出现几次的小容量机会；
> 几万元事件仓不会把价格推走；可以做大资金嫌小、流程嫌麻烦的条款和制度事件；没有"踏空即失业"压力。
> **现金拿利息，宽基吃Beta，红利吃风险溢价，极端便宜时多买，其他时间少折腾。
> 真正的Alpha若出现，就当奖金；不靠奖金活着，本身就是优势。**
