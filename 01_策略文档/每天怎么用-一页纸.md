# 每天怎么用 · 一页纸（打印贴屏幕边）

> 配套《操作手册 v5.4》+ 操作助手工具。**现在是模拟盘阶段：先证明能机械执行（执行率≥95%）、扛住回撤，再谈实盘放大。下单永远自己在券商点。本工具不构成投资建议。**

## 五句铁律（先记死）

1. **市场不好就空仓**，市场好才出手。
2. **只做最强主线（Top5）里的票**，★核心更优；不在熊板块里捡便宜。
3. **不追高**：买"缩量回踩十日线"，不买已冲高 +3~5% 的。
4. **先想能亏多少再下单**（单笔只亏总资金 0.75%）；亏到位就走，赚到位分批跑。
5. 🚫 **不补仓、不加杠杆、不借钱、连亏不加倍**。

## 每天作息（动手只有两小段，其余忍住）

| 时间 | 做什么（在工具里点哪） |
|---|---|
| **晚上 18:30 后** | 「📡 数据 → 盘后刷新」(或等自动)→ 看「🎯 盯盘 → 今日待办」，填日志。⚠️**别在刚收盘(15点)就刷**——当日数据还没发布，会显示成前一天 |
| **09:15–09:25** | 看竞价：候选股高开 >4%（20cm >7%）→ 当天放弃。**别被 9:25 末秒量化骗线** |
| **09:30–10:00** | **只卖不买**：昨日触止损/到2R/危险信号的，按计划卖 |
| **10:00–14:30** | 只观察学习，**不动手**（95% 时间忍住手痒） |
| **14:30–14:50** | 先看「📈实时大盘」过**同日大盘总闸**（健康×1.0 / 走弱×0.5 / 转坏×0，**只往下砍**）→ 再**按订单票过"三道门"**买 |
| **交易时段** | 「🎯 盯盘 → 开始盯盘」，收止损/2R 提醒 |
| **平仓后** | 「平仓记账」+ 填日志，情绪清零 |

## 买之前过"三道门"（缺一不买）

1. **逻辑**：在 Top5 最强主线里（工具"主线 #"≤5），★核心更优。
2. **信号**：缩量回踩十日线不破、企稳（不是放量下跌）。
3. **风险边界**：止损价清楚，单笔只亏 0.75%。

→ **一句话客观信号**：写出"为什么买"。含"我觉得/可能/应该/跌够了"→ **不买**。

## 卖出（预先设好，先到先执行）

- **跌破止损价** → 次日开盘卖，不找借口。
- **到 2R**（工具给的目标价）→ 卖一半。
- **剩余跌破 MA10** → 次日卖；**最多持 15 个交易日**。
- **危险信号**（两根未修复阴线 / 主线被抢走 / 放量冲高滞涨 / **高点不创新高+低点下移** / 连续大换手却不涨）→ 减或清。
- **心理卖一半**：焦虑到睡不着 / 影响判断 → 先卖一半，恢复理性。
- **卖错不追回**：卖了又涨，不后悔买回。

## "小明"清单（出现任一就停手）

踏空乱买 · 套了加仓摊低 · 追涨打板 · 卖了又买回 · 连亏想翻本 · 赚几笔就膨胀重仓。

## 失控时

**连亏 2 笔** → 单笔风险砍半、降一档，回主板缩量回踩找手感。连续违纪或账户从高点回撤 **8%** → 减半降档；回撤 **15%** → 清仓停手、回模拟复盘。**停下来不交易，本身就是止损。**
