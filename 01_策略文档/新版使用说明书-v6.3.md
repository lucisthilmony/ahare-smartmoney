# 新版系统使用说明书（v6.3 · 2026-07-03）

> 这份说明书回答两个问题：**这套系统的每个词是什么意思**、**每天到底要做什么**。
> 策略的完整规则在《零基础操作手册 v6.3》；这里只讲"怎么用"。

---

## 一、系统全景：一句话version

**账户分两层：底仓（防守型Beta主仓——拿ETF吃大盘的钱、跌市躲回撤，未证明能跑赢指数总收益）+ 卫星（小仓位练手，只做一种形态），外加三道自动保险丝。**

这是2026-07-02/03大规模回测得出的结构：个股短线在2019-2023样本外是亏钱的，真正跨时代赚钱的是"按市场状态持有强势指数ETF"；所以指数层升为主力，个股层降为受严格约束的小模块。

## 二、名词表（按重要性排序）

### 底仓（主引擎）
指用**指数ETF**建立的仓位，吃大盘/风格的beta。规则叫 **strong3**：
- **标的池**：沪深300（ETF 510300）、创业板指（159915）、科创50（588000），三选一。
- **择强**：每5个交易日比一次"近20日涨幅"，谁最强持有谁——这就是"**动量择强**"（追强者，不预测）。
- **仓位多少**：由当天的**档位**决定——进攻50%、标准30%、防守10%、空仓0%（档位见下条）。
- 回测成绩：两个时代都成立的唯一进攻部件（样本内+34%，样本外五年回撤只有指数持有的一半）。
- **已自动化（2026-07-03）**：每天14:40的Discord信号和HTML「📡数据」页都有底仓横幅，直接照做即可（详见第四节）。

### 档位 / 市场状态
每天收盘后系统自动给市场打分（沪深300在均线上方？成交额够不够？涨跌家数？），得出四档：**进攻/标准/防守/空仓**，对应总仓位上限60/40/20/0%。它同时决定底仓权重和卫星能不能开新仓。在HTML「📊市场状态」和Discord信号里都能看到。

### 卫星（个股层）
按手册规则做的个股短线波段，**定位是小资金训练装置**，不是主要赚钱来源。买什么由三道关卡决定：§4筛选 → 三道门 → **A门**。

### A门 / 回踩修复型（v6.3新增，最重要的新名词）
卫星的**开仓资格证**。过完所有老规则后，还必须同时满足四个条件才允许买：
1. **主线排名≤5**：所属行业按20日涨幅排在全市场前5（=强主线里）；
2. **RS>0**：这只票近20日跑赢沪深300（=相对强）；
3. **60日涨幅<0**：过去60个交易日整体是跌的（=位置低，没被爆炒过）；
4. **20日日均成交额2-5亿**：流动性够但不是拥挤的大热门。
翻成人话：**在最强的板块里，找一只中期还在低位、但最近已开始走强的票**——低吸修复，不追高。来源：Codex提出、经双窗口复核采纳（样本外首个跑赢"不做"的卫星配置）。HTML候选表里绿底+"A✓"=过门；**没有A型候选=今天休息，宁缺勿滥**。

### 失效判据（自动保险丝①）
系统**自我停机开关**。读你的交割记录，滚动计算最近60笔的平均盈亏（按R计）：
- 近60笔平均R<0 → 自动"**R减半+档位降一档**"（信号卡标注）；
- 连续两个检查点（每20笔查一次）都<0 → **卫星层直接停做**，信号卡改发"今日休息"。
它存在的原因：回测证明任何短线模式都会随时代死亡，而人对"模式死没死"的判断永远滞后——所以交给数字。**不足60笔时不启用**（显示"样本不足"）。

### 雷劫规则（自动保险丝②）
硬性卖出规则：**持有的票若10个交易日内涨了100%以上，之后任何一天收盘下跌 → 次日开盘无条件卖**。来源于监管异动研究："10天翻倍"会被交易所重点监控（游资叫"渡雷劫"），扛不住的两个时代都一路阴跌（样本外20日平均-8.6%）。正常卫星候选基本碰不到，这是给未来的保险丝。

### R / 2R
**R = 一笔交易愿意亏的钱** = 总资金×0.75%（50万本金→3750元）。仓位由它倒推：股数=R÷(买价−止损价)。**2R** = 赚到2倍R就卖一半落袋。交割记录里的"R倍数"=这笔净盈亏÷R（亏完止损=-1，赚到目标=+2）。

### 交割记录.csv（你唯一要手动维护的文件）
项目根目录下的表格，**每平仓一笔加一行**：`平仓日期,代码,名称,R倍数,备注`。它是失效判据的数据源——**漏记会让保险丝失灵**，建议每周和券商交割单核对。

### 总闸 / 三道门
盘中的两道老关卡（v5就有）：**总闸**=当天14:40看大盘，沪深300跌超2%或成交额<8000亿→当日不买（×0），走弱→减半（×0.5）。**三道门**=对每只候选票查：没破位、没追高、没独跌。

### 前向观察（记录不执行）
系统每晚静默记录两类数据但**不用于决策**：①情绪指数（涨停家数/炸板率/连板高度等13个指标）；②席位标志（候选是否近5日上过龙虎榜、买方是否全是游资营业部）。攒到2026-10-03按预先写死的标准评估，有效才升级成规则。**在此之前请勿自己看着这些数据改变操作**——会污染检验。

### 双窗口 / 样本外
本项目的质检标准：任何新规则必须在2024-2026（样本内）和2019-2023（样本外）**两个时代同时变好**才采纳。这套纪律两天否决了6个"看起来很好"的想法，是系统最值钱的部分。

## 三、每天的使用流程（大部分日子=什么都不做）

**自动跑的（本机MacBook Pro需保持唤醒，已确认常开）：**

| 时间 | 任务 | 你需要做的 |
|---|---|---|
| 14:40 | Discord推送**尾盘信号**（总闸+失效判据+执行卡/休息） | 看一眼；有执行卡才进入下面的手动流程 |
| 18:30 | 刷新候选池 → data.js（HTML页面数据源） | 无 |
| 18:40 | 记录情绪指数 | 无 |
| 19:10 | 记录席位/A门标志 | 无 |

**收到"今日执行卡"时（少数日子）：**
1. 14:40-14:55 打开券商，按卡上的票、现价、止损价，用HTML「🧮算仓」算股数；
2. 自己再研判一遍（资金流出没有？分时有没有尾盘跳水？）——**下单永远你手动**；
3. 买入后到HTML「🎯盯盘」加入持仓，之后按卖出规则执行；
4. **平仓当天在 交割记录.csv 加一行**。

**收到"今日休息"时（多数日子）：** 什么都不做。休息的原因会写明：总闸转坏/无候选/无A型候选/失效判据停做。**空仓是正确执行，不是错过。**

## 四、底仓怎么操作（已自动化，你只需照提醒执行）

系统每天自动算好（严格复刻回测规则，检查点相位与回测锚定对齐，无状态设计漏跑不乱）：
- **每天14:40 Discord信号**固定有一行"🏦 底仓(strong3)"：当前应持有哪只ETF、目标权重多少、下次择强日期；
- **换仓日**会明确警示："⚠️ 今日换仓：卖XXX → 买XXX"（尾盘执行）；
- HTML「📡数据」页有同样的横幅（换仓日变红）。

你要做的只有三件事：
1. 看到换仓警示 → 尾盘卖旧买新（只持一只：510300/159915/588000三选一）；
2. 目标权重变化超过总资产5% → 调仓到位；差5%以内不动，别天天折腾；
3. **账户回撤这一项系统看不到**：回撤超8%自行把底仓降一档、超15%清仓停做20个交易日。

> 底仓的性格：熊年躲得好（2022年+1% vs 沪深300 -21%），代价是V型反转会踏空。它不是"跑赢指数的神器"，是"用踏空换回撤保护的指数择时"。

## 六、常见问题

**Q：为什么天天都是"今日休息"？** A门本来就很严（回测两年只有36笔，约每月1-2笔）。系统的设计哲学是"约束你不能轻易交易"——蒸馏心法原话：系统是锁，不是印钞机。

**Q：A门的票评分反而不是最高的？** 正常。评分高的往往已涨过一段（60日涨幅为正），被A门刻意排除——回测证明追那类票两个时代都亏。

**Q：失效判据一直显示"样本不足"？** 要攒满60笔平仓记录才启用，前期它只观察。前提是你每笔都记交割记录.csv。

**Q：我能不能凭感觉买一只不过A门的票？** 系统拦不住你的手，但请先看手册§0：卫星层在上一个时代是负期望的，A门是目前证据下唯一的例外区域。要试，用模拟盘。

**Q：底仓和卫星的资金怎么分？** 底仓目标权重最高50%、卫星受档位上限约束，其余现金。两层加总不超过档位允许的总敞口。

**Q：这套东西保证赚钱吗？** 不保证。样本外验证恰恰证明大多数想法不赚钱；这套系统的价值是**把亏钱的方式一个个关掉**，并在自己失效时自动停机。先活下来，守纪律第一。
